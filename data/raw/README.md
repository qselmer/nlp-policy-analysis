# Raw official documents

Place downloaded official instruments in this folder. The folder contents are ignored by Git because legal PDFs and HTML files can be large and may have redistribution constraints.

## Rules

1. Preserve the original file without editing it.
2. Use only official government, intergovernmental, or RFMO sources.
3. Register every file in `data/templates/source_registry.csv`.
4. Record the version date, access date, language, jurisdiction, and official URL.
5. Never overwrite a previous version. Add the version date to the filename.

Suggested filename:

`jurisdiction_year_short-title_version-date.pdf`

Example:

`norway_2008_marine-resources-act_2025-01-01.pdf`
